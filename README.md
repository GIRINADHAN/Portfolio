# Giri Nadhan M Portfolio Website

A modern, responsive personal portfolio website built using **React**, **Vite**, and **Bootstrap 5**. This portfolio showcases my education, internship experience, technical skills, projects, and contact information with a clean glassmorphism-inspired user interface.

## 🚀 Live Demo

https://portfolio-girinadhan.vercel.app

## 📌 Features

✅ Fully responsive design (Mobile, Tablet & Desktop)  
✅ Modern glassmorphism UI  
✅ Hero section with dynamic typewriter effect  
✅ About section with education and achievements  
✅ Internship experience section  
✅ Interactive project showcase with category filtering  
✅ Technical skills categorized by technologies  
✅ Resume download option  
✅ Contact form with mail integration  
✅ Floating Phone & WhatsApp action buttons  
✅ Smooth scrolling navigation

## 💻 How to Run

Clone the repository

```bash
git clone https://github.com/GIRINADHAN/Giri-Nadhan-Portfolio.git
```

Open the project folder.

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Open the URL shown in your terminal (usually **http://localhost:5173**).
